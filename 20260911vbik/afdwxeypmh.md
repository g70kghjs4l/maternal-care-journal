# 新闻 | 长沙市卫生健康委领导来院宣讲党的二十届三中全会精神

> 更新时间：2026-09-11 (UTC+8)

9月19日，长沙市纪委监委驻市卫生健康委纪检监察组组长、委党组成员易立民来长沙市妇幼保健院宣讲党的二十届三中全会精神。市卫生健康委妇幼健康处处长刘翔燕，医院全体院领导，党支部书记及支部委员，中层干部参加。宣讲会由长沙市妇幼保健院党委副书记、院长贺骏主持。

易立民以《进一步全面深化改革 谱写中国式现代化崭新篇章》为题，从党的二十届三中全会的基本情况、深入学习领会习近平总书记在党的二十届三中全会上的重要讲话精神、全面准确理解《决定》提出的进一步全面深化改革重大举措、贯彻落实全会精神四个方面，结合卫生健康领域的实际情况，系统性地讲解并深入阐述了如何贯彻落实全会精神。

易立民强调，学习宣传贯彻党的二十届三中全会精神，必须以习近平总书记关于全面深化改革的一系列新思想、新观点、新论断为指导，坚持党的全面领导以推动改革，以坚定的钉钉子精神确保各项任务落到实处。在大力推动医院高质量发展的实际工作中，要展现出责任与担当，积极作为，为推进卫生健康现代化作出应有的贡献。

医院将继续深入学习贯彻党的二十届三中全会精神，确保将学习成果有效转化为推动事业发展的实际行动。以实际行动推动事业发展，为人民群众提供更加优质、高效的医疗服务，为建设健康长沙贡献力量。
